# Mariem Guibene Avatar

Add your profile photo here as `avatar.jpg` or `avatar.png`

Recommended specs:
- Square format (1:1 ratio)
- Size: 400x400px or larger
- Professional headshot or portrait
- Clear lighting and good quality

To use your photo:
1. Place your image file in this directory
2. Update the file name in `src/components/Hero.jsx` line where it says "Replace with your photo"
3. Remove the placeholder text ("MG") and uncomment the img tag
